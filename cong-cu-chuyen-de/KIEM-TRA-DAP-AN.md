# Các câu cần kiểm tra lại đáp án

Web đang dùng **đáp án được tô màu** trong file ĐÁP ÁN. Các câu dưới đây có phần lời giải ghi một đáp án KHÁC với phương án được tô. Trên web, học sinh sẽ thấy một dòng nhắc màu cam ở lời giải. Thầy/cô xem lại và báo câu nào cần sửa.

## Bảng đáp án trong file Văn ghi khác phần tô màu

Mỗi lần thi thử có file Văn riêng với bảng đáp án 30 câu. Các câu dưới đây bảng đó ghi khác với đáp án tô màu trong file ĐÁP ÁN tổng (web đang dùng phần tô màu).

- Đề 4 – Tiếng Việt câu 13: bảng đáp án file Văn ghi **D**, file ĐÁP ÁN tổng tô **C** → web đang dùng **C**
- Đề 4 – Tiếng Việt câu 29: bảng đáp án file Văn ghi **C**, file ĐÁP ÁN tổng tô **B** → web đang dùng **B**
- Đề 12 – Tiếng Việt câu 17: bảng đáp án file Văn ghi **C**, file ĐÁP ÁN tổng tô **B** → web đang dùng **B**

- Đề 16 – Tiếng Việt câu 6: bảng đáp án file Văn ghi **C**, file ĐÁP ÁN tổng tô **A** → web đang dùng **A**

## Đã đưa thêm lên web (lần sửa ngày 24/10)

Ngoài các câu đọc lại được nhờ sửa công cụ (đáp án ghi dạng "B đúng.", "Hướng dẫn: Câu 59. Chọn A.", "118.B đúng" sau cả cụm, "⇒ Đáp án: B", phương án xếp 2 cột, ký tự ẩn trong file…), có 3 câu lấy đáp án theo cách riêng:

- Đề 4 – Tiếng Việt câu 28: lấy đáp án B từ bảng đáp án trong file Văn
- Đề 8 – Tiếng Việt câu 13: lấy đáp án B từ bảng đáp án trong file Văn
- Đề 12 – kh: Dựa vào thông tin được cung cấp trong Hình 1 và Bả… → File không tô đáp án; phần HD chép nguyên văn phương án B ("Chlorophyll a và chlorophyll b hấp thụ ánh sáng xanh lục ... hấp thụ ít nhất")

## Các câu còn chưa đưa lên web

- Đề 2 – Suy luận khoa học, câu 111 ("Cho các mối quan hệ giữa hàm lượng lectin… Có bao nhiêu nhận định đúng?"): file gốc ghi nhầm phương án ("B. 1 ⇥ B. 2 ⇥ C. 3 ⇥ D. 4"), phần tô màu chọn "2" nhưng lời giải kết luận có 3 nhận định đúng — không xác định được đáp án đúng từ tài liệu. Thầy/cô cho đáp án thì mình thêm vào.
